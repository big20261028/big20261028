## Projects

### Real-Time

> AI 추천 알고리즘 기반 지능형 커뮤니티 서비스

사용자 활동 데이터와 유사도 분석을 활용해 게시글 추천 기능을 제공하는 커뮤니티 웹 서비스입니다.

**주요 역할**

- Python, Flask 기반 서버 기능 구현
- Selenium, BeautifulSoup 기반 게시글 데이터 수집 및 전처리
- MySQL 기반 게시글, 사용자 활동, 추천 결과 저장 구조 설계
- Okt, TF-IDF, Cosine Similarity, SVD 기반 추천 로직 구현
- 추천 결과를 DB에 저장하고 화면에 출력하는 흐름 구현

**기술 스택**

`Python` `Flask` `MySQL` `PyMySQL` `HTML` `CSS` `JavaScript`  
`Okt` `TF-IDF` `Cosine Similarity` `SVD` `Selenium` `BeautifulSoup`

**배운 점**

- 데이터 수집 → 전처리 → DB 저장 → 추천 결과 생성 → 화면 출력까지 이어지는 데이터 기반 서비스 흐름을 경험했습니다.
- 데이터 품질과 DB 구조가 추천 기능의 완성도에 직접적인 영향을 준다는 점을 배웠습니다.
- 제한된 일정 안에서 기능의 우선순위를 재조정하고 핵심 데이터 흐름을 끝까지 완성하는 기준을 세웠습니다.
